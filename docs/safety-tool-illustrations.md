# Safety tool illustrations

Implemented but awaiting faculty validation: Safety and Laboratory Tools v0.2.0 adds 38 realistic transparent illustrations. The 39-item register retains the earlier pointed-probe entry with its icon fallback. Version 0.1.0, prior reviews, learner progress, and class assignments are retained.

The illustrations are project-requested OpenAI image-generator outputs from October 15, 2026. Each is re-encoded as a 1254 × 1254 WebP with an alpha channel and without source metadata. The original PNG delivery remains separate from the application. Asset records retain generation provenance, usage description, caption, checksum, and pending-review status. The illustrated worksheet is decorative and is not an anatomical reference.

The normal database setup installs the new draft once, copies bundled files to the configured private module disk, and registers them through the existing protected asset route. Re-running the seeder leaves an existing version untouched. No student assignment, faculty approval, or content publication is performed by installation.

Illustrations appear beside handling notes in the existing eight-step viewer. All assets are associated with at least one step. The earlier offline downloader already retains asset records and verifies each checksum. Failed image loads fall back to a named icon; reduced-motion behavior and keyboard step controls remain available.

Additional handling text is a draft for local SOP review. General references remain in the module manifest, including the [OSHA laboratory overview](https://www.osha.gov/laboratories). These references are context, not a claim of Philippine regulatory compliance or institutional approval. Conditional equipment such as masks, aprons, dressings, and fume hoods remains subject to instructor direction and risk assessment.
