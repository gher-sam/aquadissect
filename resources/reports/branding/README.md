# SLSU Bontoc report branding

Source: the Bontoc campus quality-forms page at
https://sites.google.com/southernleytestateu.edu.ph/slsu-bontoc-documents/quality-forms/instruction/posted-on-may-2024
links the `QUALITY FORMS_DOC FILE (2023)_updated header` collection. The retained
reference is `QF-IN53 ACCOMPLISHMENT REPORT (MANCOM).docx`, Drive file
`1Z0cVitOdHgb8J3kzEHJnpprrn8Cu-XFE`, inspected on November 16, 2026.

The Bontoc variant is `word/header2.xml`, with its institutional footer in
`word/footer2.xml`. The reference also contains a Main Campus header; that variant
is not used. Campus address, email and website follow the Bontoc header.

The PNG files are the original embedded image bytes: university = image1,
Bagong Pilipinas = image3, QS Stars = image4, and SOCOTEC = image5. The source
document is retained privately under `output/reports-20261116/reference/` and is
not modified or included in the application source package.

The source form's `SLSU-QF-IN53` identifier, revision and date are not reused for
AquaDissect reports. Institutional marks are reference branding, not evidence
that the application, learning content, instruments or research are certified.
Generated document properties identify AquaDissect and the account role only.
